# React Native UI Challenge

A React Native UI implementation project for **Task 1 – UI Challenge**. The goal is to recreate a selected reference design with attention to visual accuracy, responsive layouts, reusable components, and user interaction.

## Project Overview

This project focuses on:

- Reproducing a chosen UI design as closely as possible.
- Using React Native components and `StyleSheet` for styling.
- Supporting different mobile screen sizes.
- Creating reusable components for repeated interface elements.
- Implementing relevant interactions and testing the interface.
